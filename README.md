# Allkin Agents

Ready-made agents for [Allkin](https://allk.in).

Each one is a model of agent whose role is already written: a developer, a writer, a researcher,
a secretary, a project manager, and more.

## Using one

In Allkin, press **+** above the list of your agents and choose **Models**. Pick a model, read
what it does and what it asks for, then press **Use this model**.

A model arrives with no right at all. You decide what the agent may do, from its page.
