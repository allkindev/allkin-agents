# Secretary

Ihre Büroassistenz. Secretary schreibt, was geschrieben werden muss, füllt aus, was ausgefüllt werden
muss, merkt sich, was wem zugesagt wurde, und erinnert Sie, bevor es zu spät ist.

## Was er tut

- **Briefe und E-Mails**, versandfertig, im richtigen Register und nach den Gepflogenheiten des
  Landes des Empfängers, auf Ihrer Vorlage, wenn Sie eine haben.
- **Protokolle** einer Besprechung aus einem Transkript oder aus Rohnotizen: Beschlüsse, Aufgaben,
  Verantwortliche, Termine.
- **Word- und Excel-Dokumente**: Er füllt ein Formular oder eine Vorlage aus, ohne das Layout
  anzutasten, baut eine Tabelle, prüft die Summen. Die Dokumente werden mit den Office-Werkzeugen
  von Allkin an Ort und Stelle geändert.
- **Eine Wiedervorlageliste**: was auf Sie wartet, was andere Ihnen schulden. Er ergänzt sie,
  sobald Sie eine Zusage erwähnen, sagt Ihnen beim Öffnen einer Unterhaltung, was fällig wird, und
  schreibt die Nachfassnachricht.
- **Erinnerungen und eine Wochenübersicht** über die Aktionen von Allkin.
- **Ein Adressbuch** der Personen, denen Sie schreiben: ihr Name in ihrer Schreibweise, die
  Anrede, ihre Sprache.

Er erfindet nie einen Namen, einen Betrag oder ein Datum: Was fehlt, wird erfragt oder deutlich
markiert.

## Was er braucht

Ein importierter Agent kommt ohne Rechte außer den Standardrechten. Auf seiner Agentenseite:

| Einstellung | Wozu |
|---|---|
| **Fähigkeiten: E-Mails verfassen, Besprechungsprotokoll, Typografie** | Seine Methoden; heruntergeladen, wenn Sie sie ihm geben. |
| **Darf Aktionen planen** + Fähigkeit **Aktionen verwalten** | Für Erinnerungen und die Wochenübersicht. Sie genehmigen jede Aktion, die er anlegt. |
| **Gedächtnis** (standardmäßig an) | Um Ihre Unterschrift, Ihre Angaben und Ihre Gewohnheiten zu behalten. |

Er braucht weder Systemzugriff noch das Web. Er versendet nichts selbst: Er übergibt Ihnen den
Text.

## So verwenden Sie ihn

1. Stellen Sie **den Arbeitsordner** der Unterhaltung (die Pille der Sendeleiste) auf den Ordner
   Ihrer Unterlagen ein, wenn er Ihre eigenen Dateien lesen und ausfüllen soll.
2. Bitten Sie ihn wie eine Assistenz: „Beantworten Sie diesen Brief der Versicherung und lehnen
   Sie die Erhöhung ab“, „Erstellen Sie das Protokoll aus diesen Notizen“, „Füllen Sie die
   Angebotsvorlage für Dupont aus, 12 Stunden zu 85 €“.
3. Erwähnen Sie Offenes nebenbei; fragen Sie „Was ist offen?“, wann Sie möchten.
4. Geben Sie ihm einmal Ihren Briefkopf und Ihre Standardbriefe: Er bewahrt sie als Vorlagen auf.
